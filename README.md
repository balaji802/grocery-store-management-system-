# grocery-store-management-system-
🚀 Excited to share my project: A Full-Stack Grocery Store Management System! 🛒💻
In busy retail environments, manual calculations and slow billing processes can create major bottlenecks. Inspired by modern supermarket billing frameworks, I built a web application designed to streamline order creation, automate total cost calculations, and manage grocery inventory efficiently.
Key Features:
 Dynamic Order System: Users can easily select products (like rice, fresh vegetables, or household essentials) from a dropdown list, input quantities, and let the system instantly compute individual and total costs—saving valuable time at checkout.
 Robust Backend: Built a RESTful API to handle data seamlessly, implementing robust data access objects (DAOs) for clean server-side logic.
 Relational Database Architecture: Structured an optimized database to track products, units of measure (UOM), order details, and real-time transaction history.
🔧 Tech Stack Used:
 Frontend: HTML5, CSS3, JavaScript (UI/UX)
 Backend: Python, Flask
 Database: MySQL (Managed via MySQL Workbench)
This project gave me deep hands-on experience in bridge-building between front-end interfaces, server-side APIs, and relational databases. I'm excited to keep expanding its capabilities!
